# 🌤️ Weather App

A simple and responsive weather application that provides current weather information for any city using the OpenWeatherMap API.

## 🚀 Features

- 🌍 Search for current weather by city name  
- 🌡️ Displays temperature, humidity, and weather conditions  
- 💨 Shows wind speed and direction  
- 🕒 Real-time data updates  
- 🎨 Responsive design for various devices

## 🛠️ Built With

- HTML  
- CSS  
- JavaScript  
- [OpenWeatherMap API](https://openweathermap.org/api)

## 📦 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/0ManasVerma0/weather-app.git
   ```
2. Navigate to the project directory:

    ```bash
    cd weather-app
    ```
3. Open ```index.html``` in your preferred web browser.

## 🔑 API Key Setup

This application uses the OpenWeatherMap API. To fetch weather data:

Sign up at OpenWeatherMap to obtain a free API key.

In the ```script.js``` file, replace ```'YOUR_API_KEY'``` with your actual API key:

```bash
const apiKey = 'YOUR_API_KEY';
```

## 📂 Project Structure

```bash
weather-app/
├── index.html
├── style.css
└── script.js
```
- ```index.html```: The main HTML file.

- ```style.css```: Contains styling for the application.

- ```script.js```: Handles API calls and DOM manipulation.
